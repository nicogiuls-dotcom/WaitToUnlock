WaitToUnlock

Generá un PIN aleatorio para Screen Time sin verlo nunca, copialo directo al portapapeles, y configurá cuándo se puede revelar.

1. Generar PIN oculto

Cómo lo uso en iOS
  1. Tocá Generar y copiar (el PIN no se ve, queda solo en el portapapeles).
  2. En el iPhone: Configuración → Tiempo en Pantalla → Cambiar código de Tiempo en Pantalla → Cambiar código de Tiempo en Pantalla.
  3. Mantené presionado el primer casillero del código nuevo y elegí Pegar. Repetilo en la confirmación.
  4. Volvé acá y, si querés, guardá el PIN bloqueado para recuperarlo más adelante.

2. Bloquear hasta...

El PIN recién generado todavía vive solo en memoria. Si lo guardás, se cifra con drand timelock contra una ronda futura: solo será descifrable cuando la red publique la firma de esa ronda.

PINs guardados

Todavía no guardaste ningún PIN bloqueado.

    Bloqueo criptográfico real. Los PINs se cifran con drand timelock (chain quicknet): la clave para descifrar no existe hasta que la red drand publique la ronda futura correspondiente. Ni vos ni nadie puede abrir el ciphertext antes de tiempo, ni siquiera abriendo DevTools o cambiando el reloj del sistema.

    Sin backend, sin cuentas, sin telemetría. Aleatoriedad por crypto.getRandomValues. Ciphertexts en localStorage. Para descifrar se contacta api.drand.sh.
